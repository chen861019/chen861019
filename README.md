I build end-to-end sensing systems that connect **embedded hardware**, **wireless firmware**, **mobile applications**, and **data analysis**. My public projects cover low-power BLE temperature sensing, FPGA reliability logic, Wear OS sensor acquisition, and automated imaging platforms.

## Research Interests

- **Wearable and biomedical sensing**: multi-location temperature monitoring, sensor integration, and longitudinal data collection
- **Low-power embedded systems**: Nordic nRF devices, Zephyr/NCS, BLE communication, and battery-aware firmware
- **FPGA and RTL design**: Verilog-based control logic, self-checking simulation, memory systems, and hardware-software integration
- **Research instrumentation**: embedded imaging, microfluidic experiments, and reproducible acquisition workflows

## Technical Focus

- **Embedded-to-cloud systems**: sensor firmware, BLE protocols, Android/Wear OS applications, and Firebase-backed data flows
- **Hardware-aware software**: interfaces designed around real timing, power, memory, and communication constraints
- **Verification and evidence**: separating simulation, build results, device measurements, and experimentally verified behavior
